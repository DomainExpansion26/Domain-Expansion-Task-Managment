# TechGuild — UI/UX Design Phase 3 Tasks
## Step-by-Step Work Breakdown for Execution Layer

**Document Version:** 1.0
**Date:** 2026-07-23
**File:** ui-ux-design-phase-3.md
**Role:** UI/UX Designer
**Phase:** 3 (Execution Layer) — 8 Weeks
**Prerequisite:** Phase 2 complete

**TechGuild is a Product/SaaS Platform parented by Domain Expansion Company.**

---

## Overview

Phase 3 UI/UX transforms the dashboard from a transactional interface into an intelligent work environment. Design: call interfaces, video meetings, AI task management, communication quality dashboards, AI-enhanced complaint views, native mail, and withdrawal flow updates.

**Design System:** Liquid Glass (dark mode, #0A0A0A, Tech Blue #3399FF, glassmorphic panels, backdrop-blur 20-30%)

---

## Week 1: Call Interface Design

### Task P3-UI-1.1: Audio Call Interface
**Screens to design:**
1. Incoming call notification (caller name, avatar, accept/decline buttons)
2. Active audio call (caller info, duration, mute, end call, recording indicator)
3. Call ended screen (duration, recording available, back to chat)
4. Call minimized (floating widget while browsing other sections)

**Design considerations:**
- Glassmorphic call overlay on dark background
- Recording indicator: red dot with "Recording" text
- Consent prompt: must click "I consent to recording" before call starts
- Mute button: microphone icon with state change
- Mobile: full-screen call view, swipe to minimize

**Acceptance Criteria:**
- [ ] All 4 screens designed (mobile + desktop)
- [ ] Consent prompt prominent
- [ ] Recording indicator clear
- [ ] Mute and end call buttons accessible (44px touch targets)

**Deliverables:** Audio call Figma frames

---

### Task P3-UI-1.2: Video Meeting Interface
**Screens to design:**
1. Video meeting lobby (pre-join: camera/mic check, join button)
2. Active video meeting (participant grid, controls bar)
3. Screen sharing view (shared screen prominent, participants in sidebar)
4. Participant list (names, mute status, video on/off, remove option for Lead)
5. Meeting controls (mute, video toggle, screen share, record, leave)
6. Meeting ended screen (duration, recording, participants list)

**Design considerations:**
- Participant grid: 2x2 for 4 participants, 3x3 for 9, 4x4 for 16
- Active speaker highlighted with Tech Blue border
- Controls bar: floating glass panel at bottom
- Screen share: shared content takes 70% of screen, participants 30%
- Mobile: 1 participant at a time (swipe to see others), controls at bottom
- Recording indicator: red dot top-right

**Acceptance Criteria:**
- [ ] All 6 screens designed (mobile + desktop)
- [ ] Participant grid works for 1-16 participants
- [ ] Screen share view optimized
- [ ] Controls accessible and intuitive
- [ ] Mobile experience functional

**Deliverables:** Video meeting Figma frames

## Week 2: Screen Share and File Sharing UI

### Task P3-UI-2.1: Screen Share Interface
**Screens to design:**
1. Screen share picker (choose screen, window, or tab)
2. Screen share active (shared content + participant thumbnails)
3. Screen share with annotation (drawing tools for code review)

## Week 3: Translation UI

## Week 4: AI Task Management Dashboard

### Task P3-UI-4.1: AI Task Breakdown Interface
**Screens to design:**
1. AI breakdown trigger ("Generate task suggestions" button on quest page)
2. AI suggestions review (list of suggested tasks with approve/modify/reject)
3. Task assignment (assign suggested tasks to party members)
4. AI breakdown loading state (skeleton with "AI is analyzing your quest...")
5. AI breakdown error state (if AI fails, manual task creation fallback)

**Design considerations:**
- Trigger button: glassmorphic with AI icon (sparkles or brain icon)
- Suggestions: task cards with title, description, estimated hours, dependencies
- Review: approve (green check), modify (edit icon), reject (X)
- Loading: skeleton screen with animated AI indicator
- Error: fallback to manual task creation with helpful message

**Acceptance Criteria:**
- [ ] All 5 screens designed (mobile + desktop)
- [ ] AI trigger prominent
- [ ] Suggestions review intuitive
- [ ] Assignment to members easy
- [ ] Loading and error states handled

**Deliverables:** AI task breakdown Figma frames

---

### Task P3-UI-8.2: Responsive QA
**Steps:**
1. Test all Phase 3 screens at 375px, 425px, 768px, 1024px, 1440px, 1920px
2. Test call interface on mobile (audio and video)
3. Test screen share on tablet
4. Test file upload on mobile (camera capture)
5. Verify touch targets minimum 44px

**Acceptance Criteria:**
- [ ] All screens work at all breakpoints
- [ ] No horizontal scrolling on mobile
- [ ] Touch targets minimum 44px
- [ ] Call interface usable on mobile

**Deliverables:** Responsive QA report, fixed designs

---

### Task P3-UI-8.3: Accessibility Audit
**Steps:**
1. Color contrast (4.5:1 for text, 3:1 for large text and UI)
2. Keyboard navigation (all call controls, file upload, mail)
3. Screen reader (call notifications, recording indicators)
4. Focus indicators on all interactive elements
5. ARIA labels for all icon-only buttons (mute, video, screen share)

**Acceptance Criteria:**
- [ ] Color contrast meets WCAG AA
- [ ] Keyboard navigation works for all features
- [ ] Screen reader compatible
- [ ] Focus indicators visible
- [ ] ARIA labels complete

**Deliverables:** Accessibility audit report, fixed designs
